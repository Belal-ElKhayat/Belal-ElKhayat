### 👋 About me

I'm into software and computer engineering. I write HTML, CSS, JavaScript and Python, and I like building small tools and userscripts that automate things or make the web nicer to use. I care about clean, good-looking interfaces — and I like going one layer deeper than most people bother to: reading protocol traffic, reverse-engineering closed devices, and figuring out *why* something works, not just that it does.
